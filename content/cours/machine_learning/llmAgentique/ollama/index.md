### Correctif de configuration Continue

Afin d'éviter les bugs de modification directe des fichiers par le plugin Continue :

1. Dans les paramètres (`Settings`) de Continue, **désactivez le tool** `edit_existing_file`.
2. Ajoutez la règle personnalisée suivante :
> *"use single_find_and_replace instead of edit_existing_file"*
